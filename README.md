# 📦 Warehouse WMS

**Система управления складом (Warehouse Management System)** — полнофункциональное веб-приложение для учета, контроля и управления товарами на складе, построенное на **ASP.NET Core MVC**.

![.NET](https://img.shields.io/badge/.NET-10-blue)

## 🎯 Описание

Warehouse WMS — это учебный проект, демонстрирующий разработку современного веб-приложения для управления складскими операциями. Система обеспечивает полный цикл работы со складом: от приемки товаров до их списания, с учетом партий, сроков годности и резервирования.

**Идеально подходит для:**
- Обучения ASP.NET Core MVC
- Понимания паттернов CRUD операций
- Работы с базами данных в .NET
- Изучения бизнес-логики WMS систем

## ✨ Основные возможности

| Функция | Описание |

| 📋 **Справочник товаров** | Управление каталогом продукции с артикулами и характеристиками |

## 🚀 Установка и запуск

### 📋 Требования

- **.NET 10** или выше
- **SQL Server** (Express или выше)
- **Visual Studio 2022** / **JetBrains Rider** / **VS Code**
- **Git** (опционально)

### 1️⃣ Клонирование репозитория

```bash
git clone https://github.com/vtorket3/WarehouseWMS.git
cd WarehouseWMS
```

### 2️⃣ Настройка базы данных

Откройте файл **`appsettings.json`** и укажите строку подключения к SQL Server:

```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Server=.;Database=WarehouseDB;Trusted_Connection=True;TrustServerCertificate=True;"
  }
}
```

**Параметры подключения:**
- `Server=.` — локальный экземпляр SQL Server
- `Database=WarehouseDB` — имя базы данных
- `Trusted_Connection=True` — аутентификация Windows
- `TrustServerCertificate=True` — использование самоподписанного сертификата

### 3️⃣ Применение миграций

Откройте **Package Manager Console** в Visual Studio и выполните:

```powershell
dotnet ef database update
```

Или используя CLI:

```bash
dotnet ef database update
```

### 4️⃣ Запуск приложения

**Через Visual Studio:**
1. Нажмите `F5` или кнопку ▶️ **Start**

**Через CLI:**
```bash
dotnet run
```

Приложение будет доступно по адресу: **http://localhost:5000**

## 📦 Функционал по разделам

### ➕ Управление товарами

**Создание товара:** `/Products/Create`

Заполняемые поля:
- 🏷️ **Артикул** — уникальный код товара
- 📝 **Название** — наименование продукции
- 📄 **Описание** — подробная информация
- 📐 **Единица измерения** — шт., кг, л и т.д.
- ⚠️ **Минимальный остаток** — пороговое значение для уведомлений

**Редактирование товара:** `/Products/Edit/{id}`

**Удаление товара:** `/Products/Delete/{id}`
- ⚠️ **Ограничение**: товар нельзя удалить, если он присутствует на складе

---

### 📥 Приемка товара

**Путь:** `/Stock/Receipt`

**Заполняемые данные:**
- 📦 Выбор товара
- 🏢 Выбор склада
- 🔢 Количество единиц
- 📋 Номер партии
- 📅 Срок годности (дата)
- 👤 Ответственное лицо

**Действие:** "Сохранить поступление"

---

### 🔄 Перемещение товара между складами

**Путь:** `/Stock/Transfer`

**Параметры:**
- 📦 Товар
- 🔴 Склад-отправитель
- 🟢 Склад-получатель
- 🔢 Количество

**Действие:** "Переместить"

---

### 📉 Списание товара

**Путь:** `/Stock/WriteOff/{id}`

**Причины списания:**
- 🔴 Повреждение
- ⏰ Просрочка срока
- 📝 Прочие причины (вручную)

---

### 📦 Резервирование товара

**Путь:** `/Stock/Reserve/{id}`

Позволяет временно "заморозить" товар, исключив его из доступного остатка.

---

### 📊 Остатки на складе

**Путь:** `/Stock`

**Отображаемая информация:**
- 📦 Общее количество
- 🔵 Зарезервировано
- 🟢 Доступный остаток
- ⚠️ Минимальный остаток
- 📊 Статус наличия

**Цветовая индикация статуса:**

| Цвет | Статус | Значение |
|------|--------|----------|
| 🟢 Зеленый | Норма | Остаток выше минимума |
| 🟡 Желтый | Внимание | Остаток равен или близок к минимуму |
| 🔴 Красный | Дефицит | Остаток ниже минимума |

---

### 📜 Журнал операций

**Путь:** `/StockOperations`

**Регистрируемые операции:**
- ✅ Приемка товара
- ➡️ Перемещение между складами
- 🔵 Резервирование
- ❌ Списание

Каждая запись содержит:
- Дату и время операции
- Тип операции
- Затронутый товар
- Количество
- Исполнителя

## 🧠 Бизнес-логика

### Ключевые правила системы

1. **Целостность данных:**
   - Товар не может быть удален, если присутствует на складе
   - Партии неразрывно связаны с поступлениями

2. **Резервирование:**
   - Зарезервированный товар исключается из доступного остатка
   - Резерв можно отменить

3. **Сроки годности:**
   - Хранятся на уровне партии (не товара)
   - Позволяет отслеживать партии с разными сроками

4. **Цветовая индикация:**
   - Автоматически вычисляется на основе минимального остатка
   - Помогает быстро определить критические товары
